# WebstashAI

An early-access plugin for your existing [WebstashAI](https://webstashai.com) account. Research saved sources, build cited briefs, save links, review highlights, and prepare Organizer proposals.

Follow the [installation and setup guide](https://github.com/Haqbani/webstashai-plugin#installation) in the public repository. The remote MCP endpoint is [https://api.webstashai.com/mcp](https://api.webstashai.com/mcp).

1. Install the plugin in a compatible host and choose to connect WebstashAI.
2. Sign in to your existing WebstashAI account in the OAuth flow and review the requested permissions before approving access.
3. Return to your host and ask it to read your library. Review an Organizer preview before approving changes.

Exact end-to-end installation, OAuth, and tool flows have not been fully verified in every host. This is early access; report host-specific issues through the public repository.
